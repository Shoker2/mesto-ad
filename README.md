# Mesto

https://shoker2.github.io/mesto-ad-pub

Интерактивная страница с фотографиями мест. Данные профиля и карточки загружаются с API Яндекс Практикума.

## Возможности

- Редактирование профиля и аватара
- Добавление и удаление карточек
- Лайки карточек
- Просмотр фотографий в полноэкранном режиме

## Технологии

HTML, CSS, JavaScript, Vite, REST API.

## Запуск

```bash
npm install
npm run dev
```

Или:

```bash
npm run build
```
